# ADR 0002: Electron и файловое хранилище

Дата: 2026-09-27. Статус: принято владельцем, реализовано в 0.5 для Linux x64. Заменяет выбор PWA как основной платформы из [ADR 0001](0001-offline-campaigns.md); совместимый веб-режим остаётся для переноса данных.

## Причины

Телефон исключён из требований. Нужны автономное приложение для компьютера, реальные Markdown-файлы для Obsidian, локальная музыка, управление Ollama и полные резервные копии. Настольная оболочка позволяет управлять файлами и процессом модели без отдельного запуска сервера пользователем. Существующие интерфейс, бой, формат кампаний и бестиарий переиспользуются.

Electron выбран ради единой поставляемой версии Chromium/Node и повторного использования имеющегося JavaScript-кода. Цена — размер дистрибутива и расход памяти Chromium. Tauri потенциально уменьшает оболочку, но требует отдельной интеграции системных webview и слоя Rust; сейчас это дополнительная работа без пользовательского выигрыша для приоритетных сценариев. Это проектное решение, не результат сравнительного измерения производительности.

## Решение

SQLite содержит документы кампаний, индекс файлов, профиль и журнал операций; заметки — обычные `.md`, звук — отдельные файлы. Внешние правки сверяются перед сохранением; устаревшие ревизии отклоняются. Полная копия восстанавливается в новую папку. Существующий JSON совместим, перенос браузерных данных выполняется явно через импорт.

Renderer изолирован от Node и файловой системы. Ограниченные IPC-операции доступны только главному окну приложения. Внутренний протокол раздаёт встроенный интерфейс; localhost API памяти и ИИ сохраняет проверку origin и запрет удалённых моделей. Модель ИИ не входит в дистрибутив и загружается отдельно.

## Следствия

Linux x64 получает переносимую сборку. Установщики, подпись, автообновление и Windows/macOS требуют отдельной работы и проверки. Markdown обеспечивает переносимость текстов, но не является полной копией кампании — структурные данные остаются в SQLite. Автоматическая копия на том же диске не заменяет внешнюю. Подробные лимиты, сценарии конфликта и команды проверки — в [инструкции](../desktop.md).

Техническая основа: [Electron security](https://www.electronjs.org/docs/latest/tutorial/security), [IPC](https://www.electronjs.org/docs/latest/tutorial/ipc), [поставка приложения](https://www.electronjs.org/docs/latest/tutorial/application-distribution), [Node SQLite](https://nodejs.org/api/sqlite.html).
