# Решения и открытые вопросы

## Подтверждено исходным запросом

- Приложение помогает создавать и проводить настольные ролевые игры.
- Первая целевая система — D&D.
- В перспективе возможна поддержка других систем.
- База знаний — одна из основных частей приложения.
- Начинаем с планирования и GitHub-репозитория.

## Подтверждено ответами владельца

- Компьютер и телефон одинаково важны.
- Главные задачи: ведение боя, подготовка сюжета и запоминание событий.
- Репозиторий: `Csadow/dm-workbench`, публичный.

## Предложения, ожидающие обсуждения

| Тема | Предложение | Статус |
| --- | --- | --- |
| Рабочее название | DM Workbench | Не подтверждено |
| Имя репозитория | `dm-workbench` | Подтверждено |
| Видимость репозитория | Публичный, `Csadow` | Подтверждено |
| Первый пользователь | Один мастер | Рабочее допущение |
| Язык | Русский интерфейс | Рабочее допущение |
| Первая версия | База знаний, подготовка сюжета, цикл сессии и простой трекер боя | Предложенный объём по приоритетам владельца |
| Платформа | Адаптивное веб-приложение, возможное развитие в PWA | Предложение |
| Игровые системы | Общая часть и отдельные модули правил | Предложение |
| ИИ | Необязательное расширение после базового сценария | Обсуждается |

## Вопросы перед реализацией

1. Нужны ли работа без интернета и синхронизация одной кампании между компьютером и телефоном?
2. Какая редакция D&D нужна первой? Используются ли домашние правила?
3. Как сейчас проходят подготовка сюжета, ведение боя и запись событий?
4. Где сейчас лежат материалы и нужен ли перенос в первой версии?
5. Нужен ли доступ игроков уже в первом выпуске?
6. Насколько важна помощь ИИ в первом сценарии?

Технологический стек выбираем после ответов, прежде чем создавать каркас приложения.
