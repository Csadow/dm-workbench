# Решения и открытые вопросы

## Подтверждено исходным запросом

- Приложение помогает создавать и проводить настольные ролевые игры.
- Первая целевая система — D&D.
- В перспективе возможна поддержка других систем.
- База знаний — одна из основных частей приложения.
- Начинаем с планирования и GitHub-репозитория.

## Подтверждено ответами владельца

- После уточнения владельца целевая платформа — компьютеры. Требование телефона отменено.
- Главные задачи: ведение боя, подготовка сюжета и запоминание событий.
- Репозиторий: `Csadow/dm-workbench`, публичный.
- Требуется последняя актуальная редакция D&D. По проверке 2026-09-27 это обновлённые правила 2024 года, обозначаемые D&D Beyond как 5.5e; текущий SRD — 5.2.1. [Источники](research/tools-comparison.md).
- Работа без интернета обязательна.
- Нужны сохранение нескольких кампаний и переключение между ними.
- Автоматическая синхронизация исключена из первой версии.
- Требуется исследование аналогов; [результат](research/tools-comparison.md) подготовлен по официальным материалам и выборочному чтению исходников.

## Решения и текущие допущения

| Тема | Предложение | Статус |
| --- | --- | --- |
| Рабочее название | DM Workbench | Не подтверждено |
| Имя репозитория | `dm-workbench` | Подтверждено |
| Видимость репозитория | Публичный, `Csadow` | Подтверждено |
| Первый пользователь | Один мастер | Рабочее допущение |
| Язык | Русский интерфейс | Рабочее допущение |
| Первая версия | База знаний, подготовка сюжета, цикл сессии и простой трекер боя | Предложенный объём по приоритетам владельца |
| Платформа | Настольный Electron без регистрации; веб-версия для переноса | Переход подтверждён владельцем, реализован в 0.5 / Linux x64 |
| Хранение | SQLite, Markdown и аудиофайлы; полная копия и экспорт кампании | Реализовано, [подробности](desktop.md) |
| Перенос | Файл экспорта; импорт как новая независимая кампания | Реализовано |
| Игровые системы | Общая часть и отдельные модули правил | Предложение |
| ИИ | Только локальный Ollama, память в Markdown, без обучения весов | Реализовано; дообучение остаётся отдельным будущим экспериментом |
