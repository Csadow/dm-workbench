# Прототип 0.1

Дата: 2026-09-27. Объём изменён по уточнению владельца: приложение разрабатывается для компьютеров; телефон больше не является целевой платформой первой версии.

## Принятые решения реализации

Браузерные ES-модули, HTML и CSS без сторонних зависимостей. Node.js нужен только для локального сервера и проверок. IndexedDB хранит кампании, service worker — файлы интерфейса. Это позволяет проверить предметную модель и автономность без сервера аккаунтов и процесса сборки.

Каждая кампания — один документ в object store `campaigns`. Запись всей кампании выполняется одной транзакцией: данные и их связи обновляются вместе. Поле `revision` проверяется внутри той же транзакции. Устаревшая вкладка получает ошибку вместо перезаписи; текст в её редакторе сохраняется на экране для копирования.

Такой формат подходит ограниченному прототипу. Лимит экспортируемой кампании — 5 МБ, участников одного боя — 300, сохранённых шагов отмены — 20. Сохранение также проверяет предел размера, чтобы приложение не создавало кампании, которые невозможно восстановить через импорт.

Состояние боя меняется через функции в `domain.js`; интерфейс не рассчитывает переходы хода самостоятельно. Проверка формата и целостности находится в `backup.js`, хранение — в `storage.js`. Модуль разных игровых систем ещё не выделен; сейчас поддерживается только идентификатор D&D 5.5e.

## Готовые сценарии

| Область | Возможности |
| --- | --- |
| Кампании | Создание, редактирование, переключение, архивирование и возврат |
| База знаний | Шесть типов, теги, ссылки, обратные ссылки, поиск и фильтр |
| Подготовка | Дата и статус сессии, текстовый план сцен, связанные материалы |
| Память | Отдельные итоги сессии и журнал событий со связями |
| Бой | Участники, порядок, инициатива, раунд, HP, временные HP, состояния, концентрация, урон/лечение, отмена |
| Автономность | Запуск ранее загруженного интерфейса без сети и локальная запись |
| Перенос | JSON-экспорт всей кампании; импорт как новая копия с переназначением ID, включая историю боя |
| Компьютер | Боковая навигация, горячие клавиши, клавиатурные формы, компоновка для ноутбука |

Удаление записи убирает ссылки на неё из заметок, сессий и журнала после предупреждения. Удаление участника во время его хода выбирает следующего; пустая очередь возвращается в подготовку. При завершении боя создаётся запись в хронике, очередь и история отмены очищаются, чтобы отмена не расходилась с уже записанным итогом.

## Проверено

- Восемь проверок логики боя, целостности импорта, переназначения связей и независимости кампаний.
- Создание и редактирование через настоящий браузер, поиск и безопасный вывод текста с HTML-разметкой.
- План сессии и итоги, запись события, горячая клавиша поиска.
- Скачивание настоящего файла экспорта и загрузка его через файловый ввод.
- Неверная версия импорта не изменяет существующее хранилище.
- Имитированный отказ транзакции оставляет редактор и введённый текст открытыми; повторное сохранение проходит.
- Конкурирующее сохранение со старой ревизией отклоняется.
- Сервер остановлен, вкладка закрыта; новая вкладка без сети открывает кампании и продолжает бой. Последующее изменение сохраняется после перезагрузки без сети.
- Интерфейс просмотрен в Chromium на Linux, при ширинах 1440 и 1024 пикселя.

Скрипт браузерной проверки не заменяет испытания на реальной игре, других ОС и браузерах. Реальное исчерпание диска и миграция будущей схемы пока не испытывались.

## Ещё не реализовано

- Автосохранение каждого набранного символа: текстовые редакторы требуют кнопки «Сохранить» и предупреждают при закрытии с изменениями. Боевые действия сохраняются сразу.
- Структурированные карточки сцен с изменением порядка: план пока обычный текст.
- Несколько сохранённых встреч внутри одной кампании: пока один текущий бой, завершённые результаты остаются в хронике.
- Встроенный SRD, автоматические эффекты состояний, сопротивления, спасброски, расчёт сложности и броски кубов.
- Вложения, карта, граф, общая библиотека между кампаниями, ИИ и доступ игроков.
- История версий текстовых записей и автоматическая резервная копия в отдельный файл.
- Нативные установщики, публикация сайта и тестирование Windows/macOS.

Следующий этап — пробная подготовка и игра на компьютере владельца; затем карточки сцен, удобный просмотр материала во время игры и сохранённые заготовки боёв.
