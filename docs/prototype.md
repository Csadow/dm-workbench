# Прототип 0.5

Дата: 2026-09-27. Объём изменён по уточнению владельца: приложение разрабатывается для компьютеров; телефон больше не является целевой платформой первой версии.

## Принятые решения реализации

Основная версия — Electron с существующим интерфейсом на ES-модулях. В SQLite хранятся документы кампаний, профиль и индекс; заметки и аудио — на диске. Состояние и журнал операций с файлами фиксируются одной транзакцией. После сбоя файловые операции завершаются при следующем запуске; конфликт внешней правки не затирается. [Подробная схема](desktop.md).

Веб-версия сохраняет IndexedDB, service worker и прежний экспорт. Импорт в Electron переносит материалы в новое независимое хранилище. Устаревшая ревизия отклоняется в обоих вариантах, редактор остаётся открытым для копирования текста.

Такой формат подходит ограниченному прототипу. Лимит текстового документа — 5 МБ, аудио — 60 МБ (20 МБ на файл), импортируемой копии — 100 МБ; участников одного боя — 300, сохранённых шагов отмены — 20. Сохранение также проверяет предел размера, чтобы приложение не создавало кампании, которые невозможно восстановить через импорт.

Состояние боя меняется через функции в `domain.js`; интерфейс не рассчитывает переходы хода самостоятельно. Проверка формата и целостности находится в `backup.js`, хранение — в `storage.js`. Модуль разных игровых систем ещё не выделен; сейчас поддерживается только идентификатор D&D 5.5e.

## Готовые сценарии

| Область | Возможности |
| --- | --- |
| Кампании | Создание, редактирование, переключение, архивирование и возврат |
| База знаний | Девять типов, дерево папок, вкладки, Markdown, [[ссылки]], карта окружения, закрепление, теги, ссылки, обратные ссылки, поиск, фильтры, характеристики существ |
| Подготовка | Дата и статус сессии, текстовый план сцен, связанные материалы |
| Память | Отдельные итоги сессии и журнал событий со связями |
| Бой | Участники, порядок, инициатива, раунд, HP, временные HP, состояния, концентрация, урон/лечение, отмена |
| Звук | Локальные аудиофайлы, музыка/атмосфера/эффекты, громкость, повтор, сцены и постоянная панель |
| Бестиарий | 330 блоков официального SRD 5.2.1, фильтры, добавление в знания и бой, атрибуция |
| ИИ | Локальный Ollama, контекст кампании, история, сохранение заметок, общая память стиля, обратная связь и реальные Markdown-файлы |
| Автономность | Запуск ранее загруженного интерфейса без сети и локальная запись |
| Перенос | JSON-экспорт всей кампании с аудио; импорт как новая копия с переназначением ID, включая историю боя |
| Компьютер | Боковая навигация, горячие клавиши, клавиатурные формы, компоновка для ноутбука |

Удаление записи убирает ID-связи из свойств, сессий и журнала после предупреждения. Текстовые [[ссылки]] сохраняются как отсутствующие. Удаление участника во время его хода выбирает следующего; пустая очередь возвращается в подготовку. При завершении боя создаётся запись в хронике, очередь и история отмены очищаются, чтобы отмена не расходилась с уже записанным итогом.

## Проверено

- Тридцать две проверки логики боя, целостности импорта, переназначения связей и независимости кампаний.
- Создание и редактирование через настоящий браузер, поиск и безопасный вывод текста с HTML-разметкой.
- План сессии и итоги, запись события, горячая клавиша поиска.
- Скачивание настоящего файла экспорта и загрузка его через файловый ввод.
- Неверная версия импорта не изменяет существующее хранилище.
- Имитированный отказ транзакции оставляет редактор и введённый текст открытыми; повторное сохранение проходит.
- Конкурирующее сохранение со старой ревизией отклоняется.
- Сервер остановлен, вкладка закрыта; новая вкладка без сети открывает кампании и продолжает бой. Последующее изменение сохраняется после перезагрузки без сети.
- Интерфейс просмотрен в Chromium на Linux, при ширинах 1440, 1366 и 1024 пикселя.

Скрипт браузерной проверки не заменяет испытания на реальной игре, других ОС и браузерах. Реальное исчерпание диска не испытывалось. Обновление прежней базы IndexedDB версии 1 и импорт старого формата проверены.

## Ещё не реализовано

- Автосохранение каждого набранного символа: текстовые редакторы требуют кнопки «Сохранить» и предупреждают при закрытии с изменениями. Боевые действия сохраняются сразу.
- Структурированные карточки сцен с изменением порядка: план пока обычный текст.
- Полный справочник правил SRD (бестиарий уже встроен), автоматические эффекты состояний, сопротивления, спасброски, расчёт сложности и универсальный бросатель кубов (d20 инициативы уже есть).
- Вложения, кроме аудио, карта мира, полный граф всех записей, общая библиотека между кампаниями и доступ игроков.
- Интерфейс истории версий записей: внутренние снимки SQLite уже есть. Автоматическая полная копия в файл реализована в Electron.
- Системные установщики и автообновление; готовая переносимая сборка есть для Linux x64. Windows/macOS не проверены.

Следующий этап — пробная подготовка и игра с музыкой на компьютере владельца, затем карточки сцен и улучшения по результатам игры.

В версии 0.2 также проверяются реальное воспроизведение WAV, два одновременных слоя, короткий звук поверх музыки, общая громкость, запуск сцены, остановка при переключении кампаний и проигрывание импортированных файлов при выключенном сервере. Таймеры эффектов — напоминания до начала раунда; механика правил остаётся за мастером. Подробности и источники: [исследование](research/combat-knowledge-audio.md).


В версии 0.3 модель Ollama запускается отдельно от браузера. Для новых ответов нужны работающие локальные Ollama и сервер приложения; для чтения материалов достаточно ранее установленной PWA. Память стиля общая для всех кампаний, её резервная копия отдельная. Переписка входит в экспорт кампании. Схема кампании и IndexedDB обновлены до версии 3; импорт копий форматов 1 и 2 поддерживается. Подробности: [локальный помощник](local-assistant.md).

В версии 0.4 черновики редактора заметок сохраняются в sessionStorage этой вкладки. Markdown-память — настоящие локальные файлы, отдельные от браузерной базы. Переписка автоматически архивируется в файлы только для новых ответов; старые разговоры остаются в JSON кампании. Файловый конфликт, внешний редактор, изоляция папок, Markdown и офлайн-чтение заметок проверены. [Инструкция](knowledge-memory.md).

В 0.5 проверены реальный Electron и повторный запуск, отсутствие Node.js в renderer, запись заметок и звука на диск, внешняя правка Markdown, импорт веб-экспорта через интерфейс, локальный API ИИ, полное восстановление, отказ устаревшей записи и возобновление файлового журнала. Настольный сценарий использует детерминированный ответ ИИ; отдельно проверяется настоящая установленная модель.
