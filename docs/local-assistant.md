# Локальный помощник и память стиля

Версия 0.3. Ответы генерирует установленная на компьютере модель через Ollama. Облачного провайдера, API-ключей и автоматического переключения на онлайн-сервис нет.

## Первый запуск

В Linux x64:

```sh
node scripts/setup-local-ai.mjs
node scripts/start-local.mjs
```

Первая команда загружает официальный Ollama v0.34.4 (~1,4 ГБ архивом) с проверкой SHA-256 и Qwen3.5 4B (~3,4 ГБ). Нужны интернет, свободное место и `curl`, `tar`, `zstd`. Runtime и модель находятся в `.local-ai/` и исключены из Git. После скачивания интернет для ответов не нужен. Установочный скрипт можно повторить: Ollama продолжает загрузку модели.

Вторая команда запускает Ollama, если он не работает, и приложение по http://127.0.0.1:4173/. Если Ollama уже запущен пользователем, команда использует его и не завершает его при выходе. Созданный командой процесс завершается вместе с приложением. Для работы только с заметками без ИИ можно по-прежнему запускать `node scripts/serve.mjs`.

В Windows/macOS сначала установите Ollama с [официального сайта](https://ollama.com/download), запустите его и выполните `ollama pull qwen3.5:4b`. Затем запустите приложение. Этот путь не проверялся на Windows/macOS. На другом оборудовании можно выбрать другую **уже установленную локальную текстовую модель** в «ИИ-помощник → Модель и стиль»; скорость и качество зависят от модели и памяти.

При запуске собственного Ollama установочный скрипт задаёт `OLLAMA_NO_CLOUD=1`. Использование внешнего Ollama дополнительно ограничено прокси приложения: только HTTP loopback, установленная GGUF-модель с возможностью текстовой генерации, без `remote_model`/`remote_host` и облачных имён. Перенаправления HTTP запрещены. `DMW_OLLAMA_URL` допускает только loopback-адрес на том же компьютере.

## Что умеет

- Свободный диалог и подсказки для подготовки, импровизации, боя и итогов сессии.
- Учёт названия и описания текущей кампании, до двух сессий, текущего боя, релевантных/закреплённых заметок, последних событий и подходящих блоков SRD.
- Указание материалов, включённых в запрос, и просьба к модели ссылаться на них метками `[К1]`, `[К2]`.
- Сохранение ответа в базу знаний после просмотра и редактирования.
- Запоминание одобренных примеров («Подходит моему стилю») и исправлений («Хочу иначе»).
- Просмотр, редактирование, удаление и отдельный экспорт/импорт памяти стиля.
- Остановка запроса. При ошибке сохранения ответ остаётся на экране с возможностью повторить запись.

## Как происходит «обучение»

Это персонализация через локальную память, а не дообучение весов модели. Общий профиль стиля и до 50 записей обратной связи хранятся на устройстве отдельно от кампаний. При каждом запросе выбираются до 6 подходящих или свежих записей. Явные предпочтения можно изменить; ошибочную память — удалить. Сама модель не получает доступ к файловой системе и не меняет кампанию без действий пользователя.

История последних 100 сообщений хранится в каждой кампании и входит в её экспорт. Память стиля общая и экспортируется отдельно, чтобы импорт чужой кампании не менял личные предпочтения. В текстах памяти не стоит смешивать факты разных кампаний; для фактов предназначена база знаний конкретной кампании.

## Границы

Контекст ограничен по объёму: модель видит выборку, а не всю кампанию и не весь SRD. В запросе полезно писать имена нужных записей. Звуковые файлы не передаются модели. Ответы могут содержать ошибки; предлагаемые события не считаются уже произошедшими. Полный справочник правил не встроен — в SRD-каталоге только существа.

Ollama и локальный сервер приложения должны работать во время генерации. Если оба выключены, установленная PWA продолжает показывать бестиарий, кампании, память и переписку, но новый ответ получить нельзя. Первоначальная загрузка и обновления модели требуют интернета. Старые вкладки приложения нужно закрыть при обновлении схемы хранилища.

## Проверки

`node --test tests/*.test.mjs` проверяет контекст, изоляцию кампаний, память, миграции и ограничения локального API. `node scripts/browser-test.mjs` проверяет интерфейс с детерминированным тестовым движком, без загрузки многогигабайтной модели в CI.

Отдельная проверка настоящей установленной модели (Ollama должен быть запущен):

```sh
node scripts/test-local-ai.mjs
```

Она спрашивает факт из демонстрационной кампании и проверяет, что модель использовала заметки и запомненное предпочтение оформления. Этот тест не является полной оценкой качества ответов.

Официальные технические источники: [Chat API](https://docs.ollama.com/api/chat), [локальные модели](https://docs.ollama.com/api/tags), [Linux](https://docs.ollama.com/linux), [отключение облака](https://docs.ollama.com/faq), [Qwen3.5](https://ollama.com/library/qwen3.5).

Практическая проверка 2026-09-27: Qwen3.5 4B на Linux с RTX 4060 Laptop (8 ГБ) ответил по фактам демонстрационной кампании и выполнил сохранённое предпочтение оформления. Первый запрос с загрузкой модели занял 83 секунды; этот замер не является гарантией скорости для других запросов и компьютеров.
