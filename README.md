# DM Workbench

Автономная мастерская ведущего настольных ролевых игр для компьютера: кампании, база знаний, подготовка сессий, бой и хроника событий.

**Статус: рабочий прототип 0.1.** Целевая система — D&D 5.5e (правила 2024 года). Полный справочник SRD и автоматизация эффектов пока не встроены. Кампании хранятся в браузере на устройстве, без регистрации и синхронизации.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости и собирать приложение не требуется.

```sh
node scripts/serve.mjs
```

Откройте **http://127.0.0.1:4173/**. Создайте кампанию или нажмите «Открыть пример», чтобы попробовать «Тайны Тихой гавани» с готовыми заметками и участниками боя.

Дождитесь статуса «Готово к работе без сети». После этого приложение можно закрыть и открыть по тому же адресу даже при остановленном сервере в браузере с поддержкой service worker. Для установки отдельным окном используйте значок установки в Chrome или Edge. В обычной вкладке приложение тоже работает.

Первоначальное открытие требует работающего локального сервера либо HTTPS-хостинга. Открытие `index.html` через `file://` не поддерживается. Используйте один адрес, порт и профиль браузера: у разных адресов отдельные хранилища. Очищение данных сайта удаляет локальные кампании — сохраняйте экспорт отдельно.

## Что уже работает

- Несколько независимых кампаний, переключение, архив и восстановление из архива.
- Персонажи, места, фракции, зацепки, предметы и заметки; теги, ссылки и переходы по обратным ссылкам.
- Поиск внутри кампании по названию, тексту и тегам; фильтр по типу.
- Сессии: дата, статус, текстовый план сцен, связанные материалы и отдельные фактические итоги.
- Хроника событий со связями на записи и сессии.
- Один текущий бой на кампанию: инициатива, ручной порядок, раунды, здоровье, временные HP, состояния и концентрация.
- Урон, лечение, предыдущий ход и отмена последних 20 изменений боя; продолжение после закрытия приложения.
- Файловый экспорт и импорт новой копии с проверкой версии, ID и ссылок. Лимит прототипа — 5 МБ на кампанию вместе с историей боя.
- Защита от незаметной перезаписи при редактировании в нескольких вкладках.

Тексты сохраняются кнопкой **«Сохранить»**, действия боя — сразу. При ошибке записи редактор остаётся открытым. `Ctrl/⌘ + K` открывает поиск в кампании; `Ctrl/⌘ + Enter` сохраняет редактор.

## Проверка

Логика боя и формат резервных копий:

```sh
node --test tests/*.test.mjs
```

Сквозная проверка в установленном Chromium:

```sh
node scripts/browser-test.mjs
```

При другом имени исполняемого файла задайте `CHROMIUM`, например `CHROMIUM=google-chrome node scripts/browser-test.mjs`. Проверка запускает временный сервер и отдельный профиль браузера, останавливает сервер и проверяет повторный запуск приложения без сети. Профиль очищается после теста; скриншоты сохраняются во временную папку. Браузер теста запускается с `--no-sandbox` только для изолированной проверки на доверенном локальном приложении.

Проверены Chromium на Linux, ширины окна 1440 и 1024 пикселя. Windows, macOS и другие браузеры пока не проходили практическую проверку. Мобильная версия исключена из текущего объёма по решению владельца.

## Структура

- `app/main.js` — интерфейс и пользовательские сценарии.
- `app/domain.js` — модель кампании, операции боя, демонстрационные данные.
- `app/storage.js` — IndexedDB, атомарная запись и проверка версии записи.
- `app/backup.js` — проверка формата и перенос кампаний.
- `sw.js` — кеш интерфейса для автономного запуска.
- `scripts/serve.mjs` — локальная раздача только файлов приложения.
- `tests/` и `scripts/browser-test.mjs` — проверки.

При изменении файлов приложения обновляйте версию кеша в `sw.js`. Новая версия ждёт закрытия старых вкладок, чтобы не прерывать игру. Данные кампаний хранятся отдельно от кеша интерфейса.
