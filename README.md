# DM Workbench

Рабочее название помощника мастера настольных ролевых игр: подготовка приключений, проведение сессий и связанная база знаний кампании.

Проект находится на этапе планирования. Приложения и выбранного технологического стека пока нет. Первая целевая система — D&D; редакция уточняется. Главные приоритеты — бой, подготовка сюжета и сохранение событий; компьютер и телефон одинаково важны.

## Первый полезный результат

Мастер создаёт кампанию, добавляет персонажей и места, собирает план сессии, открывает нужные материалы во время игры, ведёт бой в простом трекере и сохраняет итоги. К следующей встрече история кампании остаётся доступной и связанной.

Интерфейс и основная документация планируются на русском языке. Поддержка других игровых систем учитывается в устройстве данных с самого начала, а реализуется после проверки первого сценария на D&D.

## Работа с репозиторием

Документы описывают предложение, а не окончательно согласованные требования. Подтверждённые решения фиксируются в `docs/decisions.md`. Задачи разработки выделяются из `docs/roadmap.md` после согласования первой версии.

Игровые данные пользователя, локальные базы, секреты и резервные копии не должны попадать в репозиторий исходного кода. В примерах используем вымышленные данные.
